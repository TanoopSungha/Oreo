# Oreo

A gentle, heartfelt game by **Snoopster Gaming** about the life of one very good dog.

Oreo is a fluffy black-and-white cockapoo puppy who comes home to Mia and her family. You live his whole life with him, from the nervous first night to a grey-muzzled old friend asleep in the evening sun.

## How it plays

- **Forty days, four chapters:** Little Oreo, Zoomies, Best friend and Old friend. Oreo grows, slows down and goes grey as the years pass, and Mia grows up beside him.
- **Big moments:** the first night, the first snow, the beach, getting lost in the park, a new baby brother, Mia leaving for university and coming home for Christmas, teaching a new puppy everything he knows. Every choice is a kind one; each makes a different memory.
- **Every day,** pick two things to do: walkies (sniff the good smells, hop the puddles), fetch (throw, then time the mid-air catch), trick training (copy the signals in order), sofa cuddles (stroke him until his heart is full), a nap in the sun, or digging for treasure.
- **Look after him:** tummy, energy and happiness. Dinner and bedtime round off every day.
- **The memory album** keeps a real snapshot of every special moment, and carries over between lives.

## Run it

```
npm install
npm start      # desktop (Electron)
npm test       # lives a whole life twenty times to check the story holds together
```

Phones and tablets use Capacitor (`npm run mobile:android`, `npm run mobile:ios`). GitHub Actions builds macOS, Windows, Linux, Android and iOS packages on every push.

## Assets

Oreo, the family, every place, the music and the sounds are all made in code. The only files are the Snoopster Gaming intro video and two free fonts, Fredoka (SIL Open Font License) and Luckiest Guy (Apache 2.0); licences are in `src/assets/fonts`. Every character is made up.
